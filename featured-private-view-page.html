Developer notes

1. Security and privacy

  1. Private: sign-in required, noindex, never in a sitemap or linked from a public page. It reads the private payments ledger (never in the wiki or the room). Payment references show only the last 4 characters. No contact values; websites are shown by code and name.
  2. Read-only for everyone except the payment listener, which writes after PayPal verifies the notice.

2. Money and ads

  1. Amounts come from the ledger, never recomputed in the browser. Paid only if PayPal confirmed; a refund or chargeback ends the placement the same minute. No ads on this page.

3. Layout

  1. Phone width first: a card per payment, renewals due first, then newest first. Every row in this mockup is EXAMPLE data.
