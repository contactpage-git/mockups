  1. FUTURE LISTING PAGE, EVERY FIELD (version 1, 2026-10-09, Page Claude Code, design desk; Kim 2026-10-09: "the listing page fully
exhaustive, every single field in the schema, we are building the future, 88+ fields"). A vision page, not the production layout:
it shows where EVERY field of CONTACT/schemas/master-listing.schema.json (v2.1) lives on one page, so we can decide order, wording
and what stays hidden. It is generated by hand from that schema: when a field is added to the schema, add one line to FIELDS below.
Sample business: "Example Office Rentals" (fake, N16). Yellow Tower is not used because nothing here may be invented about a real business.

THREE SWITCHES (all in the page, no server): "Filled" shows the sample data; "Empty" shows the template holders (every field has one:
"Add photo" style, a small grey link that opens @page.me on WhatsApp with a plain prefill, ref last, N37). "Visitor" / "Owner":
the owner also sees the private block at the end (registry, tax id, verification, provenance, licences), always labelled
"Only you see this"; visitors never get it in the page or the JSON-LD (schema: collector-only and private fields). "Field names"
adds the schema key and number under each label for the developer.

RULES APPLIED: gated fields (telephone, whatsapp, messenger, email, contactPoint) show only masked in the page and open the security
check (kb/contact-gate rules); employees show owner/director name and title only; prices only from the owner (never scraped);
priceRange is for hospitality, not B2B (schema #74), so it shows only when there is data; taxID, _registry, _verification,
_provenance, _media_license, nextCheckAt and hiddenSections are never public. No star ratings, no negative notes (agent-channels.md).
IF a visitor sees an empty field: one quiet grey line. IF the owner hid a section (hiddenSections, owner layer 7): it is not drawn
for visitors and drawn greyed for the owner. OPEN FOR KIM: (a) whether visitors see holders at all or only owners (design-state
Waits 3; Kim's 2026-10-09 words say holders on the page); (b) order of the sections; (c) the Community notes section stays last
public section and cannot be hidden (agent-channels.md decision 6).
