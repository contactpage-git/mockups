Developer notes: Security check

The notes written into the mockup's source, summary first, then in page order (top to bottom). Sample data only; contact values are masked.

  1. DEVELOPER SUMMARY: THE SECURITY CHECK (Kim 2026-10-07)
1. The slide is ONLY the UI. "No separate check: just a slide, and the slide has the security check built in." The
   security comes from Cloudflare Turnstile behind it, not from the slide itself.
2. Turnstile: Managed mode, appearance "interaction-only", execution "execute". Call turnstile.execute() when the drag
   starts, so the token is ready when the slide ends. Turnstile has no slide mode; the slide bar is ours.
   Docs: https://developers.cloudflare.com/turnstile/concepts/widget/
3. Server: validate the Turnstile token with Cloudflare siteverify BEFORE releasing any contact value. No valid token,
   no details. The client never decides on its own.
4. Slide telemetry (pointer path, timing, speed variance, vertical jitter) is a hint only, never a pass. Parked for MVP.
5. MVP SCOPE: our own simple slide bar + hidden Turnstile (Cloudflare handles IP/reputation). No own bot-detection
   system for MVP. A full slide unlocks unless Turnstile asks for an interaction; then its box shows inline above the slide.
6. Fallbacks: keyboard (handle is role="slider": Enter, Space, arrow keys, End) and the "or tap here" link both go
   through the visible Turnstile box. The "I am…" choice must be picked first, else a hint and the slide snaps back.
Rejected: puzzle sliders (GeeTest etc.), solver services beat them for about $1 per 1,000. If we leave Cloudflare: Cap.js
(self-hosted, free).
  2. Gate is noindex, follow and has NO canonical (N14, N17).

PER-BLOCK SCENARIOS
- Table: one row per value that exists (main first); no row for a missing channel; never a website row; community notes only when 1+ exist.
- Closed or opted-out listing: no roles, tick, button or table; "no longer active" + same category in the same city.
- Returning visitor with cp_verified: the gate is skipped, the details open directly.
- Tick fails or the script can't load: plain message + the house ad's WhatsApp agent as the way forward. No details.
