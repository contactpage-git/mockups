  4. WHY IT IS THIS WAY (reasons and lessons)
- Cloudflare Turnstile (the security check on every contact details page) requires our privacy policy to reference its Turnstile Privacy Addendum; the old page mentioned no security check at all.
- The old page was a generic generator text (log files, DoubleClick DART cookie) with no date and no contact. Kim 2026-10-07: a complete new policy, not a patch.
- It says what the site really does: server logs, Google Analytics, AdSense, the Turnstile check, the "I am…" choice, the cp_verified cookie (1 year), taps and "did it work" answers, owners' WhatsApp and email messages. Features not built yet are worded "where offered" or "may", so the text stays true either way.
- The free Basic plan does not include the AI agent (that is Plus), so the text never promises the agent to everyone.
- Plain language, short sections, "the short version" first: most readers only want to know whether we sell their number (we never sell contact lists).
- Run by Yellow Tower Co., Ltd. (Kim); privacy@contact.page works through the catch-all, so no new mailbox is needed.
- Not legal advice: a lawyer's look is wise before the EU/UK traffic grows.
