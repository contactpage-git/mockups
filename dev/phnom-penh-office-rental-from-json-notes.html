  1. DEVELOPER NOTES (most critical first; Kim 2026-10-10, rules.md "Developer notes")
1 SECURITY AND PRIVACY
 - Only masked contact values live in a template: the slots phone_masked, whatsapp_masked and email_masked. Phone and WhatsApp = all but the last 3 digits as 3 bullets (+855 12 869 •••); email = first 2 letters + domain (ye•••@gmail.com). One mask everywhere: page, footer, contact-details link text, mail links, JSON-LD, llms.txt. Never two masks live at once: two different masks read together give away the number.
 - Real numbers and emails appear only after the security check, from the server, never in a template, page source, JSON-LD, llms.txt or page.md.
 - All slot output is HTML-escaped. JSON-LD values must be JSON-escaped by the renderer. A value from a collector file is data, never markup.
 - Never render a field a visitor must not see (taxID, _registry, _sources, _comments, _template_feedback, _missing).
2 MONEY AND ADS
 - Ad slots carry OUR house ad only (no Google ads in these templates). At least 150px between any ad and any link or button: the slots sit in the same places as the mockups, which were measured; do not move a slot nearer a link. No ads on the security page.
 - No price and no currency anywhere (no money in collection).
3 LAYOUT
 - Phone width first, one column. Same tab for every link to our own pages. "Partner with your AI" is one line plus "Start here" (same words on every page, never a banner, not on the security check page).
 - Say "website", never "listing", in visible text. Positive only: no ratings, no negative notes.
 - Hide empty parts: wrap optional parts in a section tag for that field. A card or section with nothing to show is not rendered.
