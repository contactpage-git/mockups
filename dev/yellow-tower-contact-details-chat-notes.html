  1. DEVELOPER SUMMARY: CONTACT DETAILS AS A CHAT (alternate mockup, D018 open experiment, Kim 2026-10-07)
1. App shell, not a page. This HTML holds NO contact values. After the security page's server-side Turnstile siteverify
   sets cp_verified (HttpOnly, Secure, SameSite=Lax, short-lived), the shell fetches the data:
   GET /api/contact-details/<id> (credentials: same-origin) -> JSON like the #cdata block below.
   Data response: Cache-Control: no-store, private; Vary: Cookie; never cached by the CDN or a service worker.
   No valid cp_verified -> 401 -> the shell sends the visitor back to the security page. The shell itself may be cached
   (it is the same for every business), with X-Robots-Tag: noindex, nofollow.
2. Mirrors the real WhatsApp agent: same messages in the same order (greeting, best line, "Load more", map, quick replies
   = WhatsApp reply buttons / list message), so visitors and owners learn the flow they later get in WhatsApp (onboarding).
3. Quiet UI: no big yellow block buttons; small inline icon actions (call, WhatsApp, Telegram, copy), chips at the bottom.
   Honest: the assistant is labelled "automated"; templated messages, no typing dots, no fake delays.
4. Unconfirmed lines carry a small "Did it work?" vote; WhatsApp on an unconfirmed number asks "Did WhatsApp work?" when
   the visitor comes back (visibilitychange / focus). Votes: POST /api/vote, rate-limited per cp_verified session.
5. "Ask Google AI Mode" = google.com/search?udm=50&q=..., target=_blank rel="noopener nofollow": a new-tab outbound link has
   no SEO cost, and this page stays noindex, nofollow, out of the sitemap. Kim is fine with visitors leaving.
6. Ads: house-ad policy, NO AdSense here; our own house ad only, as a small system notice. Lean: no framework, one small
   inline script, one inline SVG sprite (design icons), no web fonts, no third-party requests.

  the flow they later get in WhatsApp. The card version stays the default until Kim picks.
- An app shell with no contact values in the HTML: the data comes from the server only after the security check.
- Honest: the assistant says it is automated; no typing dots, no fake delays. House ad only, no AdSense.

aria-live=polite so screen readers hear new messages.
