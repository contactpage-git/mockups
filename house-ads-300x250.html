Prompt

Make an in-house ad for contact.page.
Size: fixed 300x250 box. CSS and text only: no images, no JavaScript, no fonts to load.
Look: quiet. White card, 1px light grey border, 12px corners, a 4px yellow line on top, the small contact.page mark (yellow highlight on ".page"), one headline, one grey sub line, one yellow-outlined button. Clearly ours, never like a Google ad (no "Ad choices" look, no bright fills, no stock photos).
Copy: short and positive, one idea per ad, plain words that work in any country. Say "page" or "website", never "listing". No city names, no numbers or studies, no promises we cannot keep, no "AI employee".
Action: the whole ad is one link that opens a ready-made email, the same one the page footer uses. Edit and Claim go to the page code address (code@contact.page); Start your.contact.page goes to hello@contact.page. The subject and the last line carry "(ref code action)".
Variants so far: Start your.contact.page, Claim this page, Edit this page. Copy source: kb/ads.md (V2-F, V2-B, V2-E).
